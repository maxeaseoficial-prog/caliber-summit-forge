# Caliber Ascent

PROJETO

CÁLIBER SUMMIT — Landing Page / Site Oficial

OBJETIVO DESTA ETAPA

Criar SOMENTE a fundação profissional do site e a página inicial (Home) do evento Cáliber Summit.

Esta NÃO é a etapa de desenvolver o site completo.

Quero estabelecer:

- identidade visual;

- design system;

- direção artística;

- estrutura da Home;

- componentes reutilizáveis;

- tipografia;

- animações e motion;

- responsividade;

- experiência premium;

- base técnica limpa para evolução posterior.

NÃO criar nesta etapa:

- painel administrativo;

- Supabase;

- autenticação;

- checkout;

- pagamento;

- área do participante;

- blog;

- CMS;

- páginas internas completas;

- integrações externas;

- banco de dados;

- funcionalidades fictícias;

- sistemas complexos.

O objetivo é gastar o mínimo necessário de implementação agora e obter uma Home visualmente excepcional que possa ser expandida depois.

1. MARCA

==================================================

Nome oficial:

CÁLIBER SUMMIT

Conceito central:

MENTALIDADE • ESTRUTURA • PROSPERIDADE

O Cáliber Summit é um evento empresarial premium voltado para empresários, líderes e pessoas que desejam elevar seu nível de pensamento, estrutura empresarial, conexões e resultados.

A marca deve comunicar:

- força;

- autoridade;

- transformação;

- liderança;

- estratégia;

- crescimento;

- prosperidade;

- excelência;

- exclusividade;

- alto nível empresarial.

A identidade anterior do projeto utilizava o conceito de “A Forja”.

A nova marca é CÁLIBER SUMMIT.

Não utilizar “A Forja” em nenhuma parte visível da nova interface.

O conceito visual de fogo, metal, calor, transformação e energia pode permanecer, mas agora deve representar a identidade própria do Cáliber Summit.

- carvão;

- vermelho incandescente;

- landing page de infoproduto barata;

- cassino;

- e-sports;

- fantasia medieval;

A sensação desejada é:

“Poder, transformação e sofisticação empresarial.”

6. MOTION E ANIMAÇÕES

==================================================

Motion é importante para a identidade.

Porém:

NÃO transformar a página em demonstração de efeitos.

Animações devem transmitir peso, sofisticação e energia.

Implementar:

- entrada cinematográfica do Hero;

- fade + translate suave em textos;

- reveal de headlines;

- stagger controlado;

- parallax MUITO sutil em elementos atmosféricos;

- microinterações nos CTAs;

- underline/line animation na navegação;

- pequenas mudanças de iluminação no hover;

- elementos surgindo conforme scroll;

- transições suaves entre seções.

Duração preferencial:

aproximadamente 400ms–900ms dependendo do elemento.

Evitar:

- bounce;

- animações infantis;

- objetos voando;

- movimentos aleatórios;

- scroll hijacking;

- cursor customizado exagerado;

- partículas demais;

- animação contínua pesada;

- efeitos que prejudiquem leitura.

Respeitar:

prefers-reduced-motion.

Se uma biblioteca de motion já estiver disponível no projeto, reutilizar.

Não adicionar uma biblioteca pesada apenas para um efeito simples.
